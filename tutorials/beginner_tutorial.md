# Workshop Translator 新手入门教程 (Beginner's Guide)

欢迎使用 **Paradox Mod 本地翻译工作台**！只需简单几步，即可将本机 Steam 创意工坊中订阅的英文 Mod 自动翻译为简体中文（或繁体中文、日文、韩文等）。

> [!TIP]
> **首次使用准备**：在开始前，请先展开页面右侧下方的 **「API 与 Steam 库设置」**，填入你的 **API Key**（以及对应的 Base URL 与模型名称，如 deepseek-chat、gpt-4o-mini 等），点击 **「保存配置」**。

---

## 核心流程一览

```
[1. 刷新目录] ➔ [2. 选择 Mod] ➔ [3. 扫描 Mod] ➔ [4. (可选) 导入旧译文] ➔ [5. 开始翻译] ➔ [6. 完成汉化] ➔ [7. (可选) 导出独立 Mod]
```

---

### 第 1 步：扫描 Steam 创意工坊目录
1. 在左侧 **「本机创意工坊」** 面板顶部，点击 **「刷新目录」** 按钮。
2. 程序会自动读取电脑上 Steam 安装清单（读取 `steamapps/workshop/appworkshop_<AppID>.acf`），列出所有已订阅安装的 Mod。
   > 此步骤仅读取本地清单，不会消耗网络流量或任何 API 费用。

### 第 2 步：选择要翻译的 Mod
1. 点击搜索框下方的 **游戏分类标签**（群星 `Stellaris`、钢铁雄心4 `HOI4`、欧陆风云4 `EU4`、十字军之王3 `CK3`、维多利亚3 `Vic3`）。
2. 在列表中找到你想汉化的 Mod 并点击它（亦可在上方搜索框中直接输入 Mod 名字或创意工坊 UID 快速检索）。

### 第 3 步：扫描 Mod 本地化词条
1. 选中 Mod 后，在右侧 **「翻译工作台」** 中点击绿色按钮 **「扫描此 Mod」**。
2. 程序会读取该 Mod 的英文原文件与本机已有的中文文件，精确统计出：
   - **总条目**
   - **已翻译**
   - **已缓存**
   - **未翻译**
   - **需更新**（原文改动过的词条）
   - **格式错误**（变量损坏需修复的行）

### 第 4 步：(可选) 导入旧汉化或共享缓存
如果你手头已经有以前的汉化文件（`.yml`）、历史汉化文件夹，或别人分享的译文包（`.zip` / `.cache.json`）：
1. 点击 **「导入译文」** 按钮；
2. 选择本机对应的文件或目录，填写导入来源名称（留空将自动按日期命名）并确认；
3. 程序会自动比对英文原文哈希，把完全吻合的中文存入缓存。**这部分词条在后续翻译时将直接命中复用，无需重复扣除 AI Token**。
> *注：如果是全新 Mod 或无需导入旧译文，直接跳过此步。*

### 第 5 步：开始 AI 翻译
1. 点击右侧蓝色按钮 **「开始 AI 翻译」**，在弹出的确认对话框中确认参数。
2. 程序会自动将「未翻译」和「需更新」的词条分批打包发送给你配置的 AI 模型。
3. 可在底部的 **「任务进度」** 日志窗口中实时监控当前翻译进度与每个文件的处理状态。

### 第 6 步：完成与入库
1. 当底部状态恢复为 **「待命」**，且 Mod 状态徽章变为绿色的 **「已完全翻译」** 时，翻译后的中文本地化文件已自动备份并直接写回到原 Mod 文件夹中。
2. 打开 Paradox 游戏启动器，启用该 Mod 进入游戏，即可看到汉化效果！
3. *(小贴士)*：若想微调某些特定句子的翻译，点击 **「浏览翻译条目」**，在表格中直接双击编辑并保存。

### 第 7 步：(可选) 导出独立 Mod 或备份分享
- **生成独立汉化 Mod**：
  点击 **「生成翻译 Mod」**，可一键在系统 `Documents/Paradox Interactive/<游戏>/mod/` 目录下生成外挂式独立汉化 Mod。即使 Steam 后续自动更新覆盖了工坊原 Mod，你的独立汉化 Mod 依然有效！
- **导出共享备份包**：
  点击 **「导出中文 + 哈希 (.zip)」**，可下载包含全部中文 YML 和 SHA-256 哈希缓存的压缩包，方便存档或分享给其他玩家无缝导入。
