# Paradox AI Translator Tutorials

Welcome to the **Tutorials** directory! This directory is dedicated to step-by-step user guides, walkthroughs, and tutorials for Paradox AI Translator.

## Available Tutorials

1. [Beginner's Guide (新手入门教程)](beginner_tutorial.md)
   - Step-by-step walkthrough for first-time users.
   - Covers scanning, selecting mods, importing legacy translations, running AI translations, in-place entry review, and exporting standalone translation mods.

## Structure for Future Tutorials

When adding new tutorials to this directory:
- Use English filenames (e.g. `glossary_guide.md`, `batch_translation.md`, `custom_rules.md`).
- Markdown format (`.md`).
- Keep guides concise, actionable, and structured with clear step-by-step milestones.
