# 工坊简介文件导入

## 命令行自动上传（推荐）

这是独立本地脚本，无需部署到网站。上传项目现有多语言合集：

```sh
.venv-workshop/bin/python scripts/workshop_description.py \
  --item-id 3823983244 --bundle \
  --file dist/steam_workshop_release/创意工坊简介_多版本合集.md --apply
```

只提取各编号语言章节中的 `bbcode` 代码块，不上传合集说明、章节标题或 Markdown 围栏。先完整校验合集，再按语言依次上传；任一语言失败即停止，已成功语言保留。重新运行时已一致的语言会跳过。

`workshop_description.py` 读取本地 UTF-8 文件，打开 Chrome 的 Steam 官方编辑页，自动填入指定语言简介并点击保存，然后重新读取核验。只更新简介，不修改标题、图片、Mod 文件或可见性。不调用付费 API，也不依赖 SteamCMD。依赖隔离于翻译程序运行环境。

在项目根目录执行：

```sh
python3 -m venv .venv-workshop
.venv-workshop/bin/python -m pip install -r scripts/requirements-workshop.txt
```

需要本机已安装 Google Chrome。先离线预览（将路径替换为实际文件）：

```sh
.venv-workshop/bin/python scripts/workshop_description.py \
  --item-id 3823983244 --language schinese --file /绝对路径/description.txt
```

确认后自动上传：

```sh
.venv-workshop/bin/python scripts/workshop_description.py \
  --item-id 3823983244 --language schinese --file /绝对路径/description.txt --apply
```

首次在新窗口手动完成 Steam 登录和 Steam Guard，回终端按回车后脚本自动上传，不需要再手动点击保存。脚本不接受命令行密码，不读取日常 Chrome 登录配置。默认浏览器目录为临时目录，退出后删除；如需后续复用登录，可显式添加 `--profile "$HOME/.paradox-workshop/chrome-profile"`，这会在该专用目录保留 Steam 登录态，勿分享、提交到 Git 或与日常 Chrome 配置混用。

语言参数：简体 `schinese`、繁体 `tchinese`、英文 `english`、日文 `japanese` 等，完整选项见 `--help`。正文使用 Steam BBCode，Markdown 不会自动转换。仅规范化 BOM 和换行，不改写正文。

每次实际更改前，旧简介及标题、语言、SHA-256 自动备份至 `~/.paradox-workshop/backups/` 的独立目录；可用 `--backup-dir` 指定位置。备份写入失败不会提交。恢复时以备份中的 `description.txt` 作为 `--file`，指定相同条目和语言，再执行 `--apply`。

内容一致时跳过上传。权限不足、页面结构变化或保存后不匹配会返回非零状态；提交后若网络超时，结果可能已生效，脚本不会自动重试或回滚，请先检查线上页面。Steam 服务端的额外长度、内容限制以实际保存结果为准。

本脚本使用网页自动化，不是 Steam 官方 API 客户端。2026-10-21 已通过现有登录浏览器对项目合集的 11 个语言进行真实核对：5 个语言更新并重新读取验证，6 个一致而跳过；原简介备份在本机 `app_data/workshop_description_backups/` 中。本次使用已有登录浏览器完成，命令行另开 Chrome 的登录流程尚未实测。回归测试使用模拟表单，不修改线上内容。它是独立维护工具，不加入网站部署或桌面打包清单。

## 可选：网页手动导入

`workshop-description-import.user.js` 在 Steam 的“编辑标题与描述”页面添加文件选择和撤销按钮。使用浏览器现有 Steam 登录态。

## 使用

1. 将简介保存为 UTF-8 的 `.txt`、`.bbcode` 或 `.md` 文件。Steam 使用 BBCode；脚本原样导入，不将 Markdown 转为 BBCode。
2. 打开自己的工坊条目，点击“编辑标题与描述”，先选择目标语言。
3. 若已使用用户脚本管理器，可导入同目录的 `.user.js` 文件；也可以打开浏览器开发者工具的 Console，将脚本全文粘贴运行。仅运行你已审阅的脚本，不需要关闭浏览器安全保护。
4. 在新增的“选择简介文件”入口选择文件，检查当前工坊 ID、语言和导入结果。标题保持原值。
5. 点击 Steam 原有的“保存”按钮才会上传简介。要放弃本次导入，点击“撤销本次导入”或不保存直接离开。

例如 Paradox AI Translator 的编辑入口：
<https://steamcommunity.com/sharedfiles/itemedittext/?id=3823983244>

## 边界

- 不自动提交、不上传图片、不调用翻译 API、不读取 Cookie 或账号凭据、不写浏览器存储。
- UTF-8 BOM 会被移除，换行由浏览器文本框规范化；BBCode 和其他正文原样保留。
- 导入覆盖当前编辑框全文；撤销仅保留最近一次成功导入前的内容，页面刷新后失效。保存后的版本不属于脚本撤销范围。
- 切换语言会清除撤销记录；文件读取期间若语言或正文变化，不覆盖编辑框。
- 无效 UTF-8、空白文本、空字符、超过 1 MiB 或超过编辑框长度限制的内容会拒绝导入。Steam 服务器仍可能有额外限制，以实际保存结果为准。
- 这是独立浏览器辅助脚本，不属于桌面安装包或网站运行时，不会自动发布工坊内容。
