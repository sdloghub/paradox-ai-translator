翻译工作台

在左侧选择一个 Mod，查看路径并开始翻译。
开始前自动整合已有中文、数据库和匹配缓存，只将缺失或原文变化的条目发送给模型接口，可能产生费用。英文文件会复制到独立工作目录。完成后备份并回写中文文件，报错行保留英文；覆盖前会保存已有文件。
解析或翻译失败的行保留英文，其余条目继续翻译；任务结束显示报错行数与位置。Steam 更新可能覆盖回写文件，可从备份再次复制。
API 与 Steam 库设置
切换时复制当前配置和已保存的接口；同名但内容不同的旧接口会保留为另一份配置。翻译缓存和备份继续保存在数据目录。
API Key 保存到本机 JSON，不返回浏览器。

STEP 1 / 2

选择导入文件或文件夹

请先选择本机中文 YML 文件、包含中文的文件夹、导出的 ZIP 压缩包或缓存 JSON。选择完成后将进入提示与导入者命名步骤。
STEP 2 / 2

确认导入提示与导入者名称

已选导入路径：
提取所选中文文件并与当前 Mod 英文建立缓存对应关系。
导入缓存无法检查是否需要更新：带哈希缓存仅校验本机英文，无法检查 Steam 尚未安装的更新；无哈希中文文件无法判断原文是否更新，请确认来源版本。已有哈希不同的旧译文、冲突译文和格式错误会自动跳过。
提示：可留空自动命名，系统会按日期与序号自动生成来源名称（如「翻译-2026-10-17-1」）。
